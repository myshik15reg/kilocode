2.  **No Protocol, No Code**: All code changes must be preceded by a defined protocol.
3.  **Update Plan**: Keep the plan updated as tasks progress.
4.  **Log Decisions**: Document key decisions and their rationale.
5.  **Clean Finish**: Ensure all tasks are completed with tests and documentation updates.

## Project Overview

Kilo Code is an open-source AI coding agent for VS Code that generates code from natural language, automates tasks, and supports 500+ AI models. It features:

-   Code generation from natural language
-   Self-correction capabilities
-   Terminal command execution
-   Browser automation
-   Integration with latest AI models (Gemini, Claude, GPT)
-   MCP Server Marketplace support
-   Multi-mode operation (Architect, Code, Debug, etc.)
