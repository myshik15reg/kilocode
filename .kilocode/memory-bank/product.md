# Product

AlfaCode assistant is a VS Code AI coding agent focused on practical coding workflows, broad provider/model support, and configurable cost-quality tradeoffs.

## UX Direction

- Keep advanced controls visible but grouped.
- Make token-saving behavior understandable and one-click.
- Prefer profile routing over forcing one expensive model for every subtask.

## AlfaCode Settings Strategy

The `AlfaCode` tab acts as the home for AlfaCode-specific workflow tuning:

- context and condensing presets
- task-strategy guidance for local vs compact vs new task decisions
- helper-task profile routing
- recommended badges for main vs helper profile choices
- system notifications
- AlfaCode display controls
- fast apply and image generation integration
