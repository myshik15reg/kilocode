# Product Context

## Vision
To create the most capable, flexible, and developer-friendly AI coding agent that seamlessly integrates into the VS Code workflow, empowering developers to build better software faster.

## User Experience (UX) Principles
1.  **Seamless Integration**: The agent should feel like a natural extension of VS Code, not a separate tool.
2.  **Transparency**: Users should always know what the agent is doing and why.
3.  **Control**: Users must have final say over code changes and command execution.
4.  **Flexibility**: Support for various workflows, languages, and AI models.
5.  **Reliability**: Consistent performance and accurate code generation.

## Key Features & User Stories

### Core Coding
-   **Code Generation**: "As a developer, I want to describe a feature in English and have the agent generate the corresponding code."
-   **Refactoring**: "As a developer, I want the agent to improve the structure and readability of my legacy code."
-   **Debugging**: "As a developer, I want the agent to analyze error logs and suggest fixes."

### Task Automation
-   **Terminal Commands**: "As a DevOps engineer, I want the agent to run build scripts and deployment commands safely."
-   **File Management**: "As a developer, I want the agent to create, move, and edit files across the project structure."

### Advanced Capabilities
-   **MCP Integration**: "As a power user, I want to connect custom tools via MCP servers to extend the agent's capabilities."
-   **Browser Automation**: "As a QA engineer, I want the agent to run E2E tests by interacting with a browser."
-   **Mode Switching**: "As an architect, I want to switch to 'Architect Mode' to plan high-level system design before coding."

## Differentiators
-   **Open Source**: Fully transparent and community-driven.
-   **Model Agnostic**: Support for 500+ models, avoiding vendor lock-in.
-   **Deep Integration**: Native VS Code API usage for better context awareness.
-   **MCP Support**: First-class support for the Model Context Protocol.

## Roadmap
-   **Short-term**: Enhance MCP server discovery and management.
-   **Mid-term**: Improve multi-agent collaboration and specialized modes.
-   **Long-term**: Autonomous project management and self-evolving codebases.
