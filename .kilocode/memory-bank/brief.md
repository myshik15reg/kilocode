# Project Brief

## Project Name: Kilo Code

## Overview
Kilo Code is an advanced, open-source AI coding agent extension for VS Code. It empowers developers to generate code, automate tasks, and interact with their codebase using natural language, leveraging state-of-the-art AI models.

## Core Goals
1.  **AI-Powered Coding**: Enable seamless code generation and modification through natural language prompts.
2.  **Task Automation**: Automate repetitive coding tasks, refactoring, and terminal operations.
3.  **Extensibility**: Support MCP (Model Context Protocol) servers to extend functionality.
4.  **Multi-Model Support**: Integrate with a wide range of AI models (Gemini, Claude, GPT, etc.) via OpenRouter and other providers.
5.  **Robustness**: Ensure code quality through self-correction and automated testing.

## Key Features
-   **Natural Language Interface**: Chat-based interaction for coding tasks.
-   **Multi-Mode Operation**: Specialized modes for Architecture, Coding, Debugging, etc.
-   **Terminal & Browser Integration**: Execute commands and automate browser actions.
-   **MCP Server Support**: Extend capabilities with external tools and resources.
-   **Transparent Pricing**: Direct access to model providers with no markup.

## Target Audience
-   Software Developers
-   System Architects
-   DevOps Engineers
-   Anyone using VS Code for development

## Success Metrics
-   User adoption and retention (VS Code Marketplace installs).
-   Efficiency gains in coding tasks.
-   Community contribution and engagement.
-   Reliability and accuracy of generated code.

## Current Focus
-   Stabilizing core functionality.
-   Expanding MCP server integration.
-   Improving multi-mode workflows.
-   Enhancing documentation and onboarding.
