# Навык: 1C (firm) — Template generator (генерация по шаблону)

## Когда использовать

- Интеграция или разработка, где требуется формировать файлы по шаблону (в т.ч. PDF).

## Источник (firm SoT)

- Требования к методу генерации: [`template-generator.md`](../../sources/1c-alfa/template-generator.md)

## Ключевые требования (firm)

- Высокоуровневый метод принимает данные заполнения (структура), имя шаблона и признак конвертации в PDF; возвращает двоичные данные файла.

Основание:

- [`template-generator.md#api`](../../sources/1c-alfa/template-generator.md#api)

## Чеклист (что проверить)

- [ ] Вызов метода обеспечивает передачу структуры данных заполнения.
- [ ] Признак конвертации в PDF выставляется только при необходимости.
- [ ] Результат — двоичные данные файла (тип корректно обрабатывается вызывающей стороной).

## Evidence (как подтвердить)

- Пример вызова/контракт (санитизировано, без данных) или запись в `<TICKET>`.
