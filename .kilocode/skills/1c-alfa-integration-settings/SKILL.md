# Навык: 1C (firm) — Хранение настроек интеграции

## Когда использовать

- Добавление/изменение настроек интеграции с внешними системами.
- Требуется определить, какие настройки обязательны и какие нужно хранить в безопасном хранилище.

## Источник (firm SoT)

- Правила подсистемы настроек интеграции: [`integration-settings.md`](../../sources/1c-alfa/integration-settings.md)

## Ключевые требования (firm)

### 1) Обязательность заполнения

- Использовать признак `ЗаполнятьОбязательно` для обязательных параметров.

Основание:

- [`integration-settings.md#settings-flags`](../../sources/1c-alfa/integration-settings.md#settings-flags)

### 2) Безопасное хранилище

- Использовать признак `ХранитьВБезопасномХранилище` для секретных значений.

Основание:

- [`integration-settings.md#settings-flags`](../../sources/1c-alfa/integration-settings.md#settings-flags)

## Чеклист (что проверить)

- [ ] Для каждого значения определено: обязательно ли оно (`ЗаполнятьОбязательно`).
- [ ] Для секретов включено безопасное хранение (`ХранитьВБезопасномХранилище`).
- [ ] Не хранить в явном виде `<HOST>`/учётные данные в документации/логах.

## Evidence (как подтвердить)

- Скриншот карточки вида настройки (значения скрыты).
- Запись в `<TICKET>` о добавленных/изменённых параметрах и их флагах.
