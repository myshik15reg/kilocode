# Навык: 1C (firm) — Права доступа и роли

## Когда использовать

- Создание/изменение ролей.
- Добавление новых объектов метаданных, которые требуют прав.

## Источник (firm SoT)

- Раздел про проектирование ролей и ограничения: [`REG`](../../sources/1c-alfa/reg.md#access-control)

## Ключевые правила (firm)

### 1) Роли должны быть «атомарными»

Роли дают доступ к элементарным функциям и собираются в профили пользователей.

Основание: [`REG`](../../sources/1c-alfa/reg.md#access-control)

### 2) Запрет интерактивного удаления ссылочных объектов

Ни одна роль (включая «ПолныеПрава» и «АдминистраторСистемы») не должна давать право на интерактивное удаление ссылочных объектов.

Основание: [`REG`](../../sources/1c-alfa/reg.md#access-control)

### 3) Устаревшие объекты

Устаревшие объекты метаданных (с префиксом «Удалить») исключаются из всех ролей, кроме «ПолныеПрава» или «АдминистраторСистемы».

Основание: [`REG`](../../sources/1c-alfa/reg.md#access-control)

## Мини-чеклист применения

- [ ] Для каждого нового объекта определена элементарная функция.
- [ ] Для ссылочных объектов проверен запрет интерактивного удаления.
- [ ] Устаревшие объекты «Удалить\*» исключены из ролей (кроме исключений).
