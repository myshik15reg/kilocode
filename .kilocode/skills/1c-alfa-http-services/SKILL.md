# Навык: 1C (firm) — HTTP-сервисы и Swagger

## Когда использовать

- При добавлении нового HTTP-сервиса.
- При изменении контрактов существующего сервиса (методы/параметры).

## Источник (firm SoT)

- Требование документировать HTTP-сервисы через Swagger в УЗ: [`REG`](../../sources/1c-alfa/reg.md#http-swagger)

## Мини-процесс (firm)

1. Описать новый HTTP-сервис через подсистему «Работа со Swagger» (УЗ).
2. Заполнить данные сервиса в табличной части элемента справочника «Корневой узел URL» (УЗ).
3. Указать методы и параметры методов.
4. Обновить опубликованную информацию («Обновить информацию по сервисам»).

Основание: [`REG`](../../sources/1c-alfa/reg.md#http-swagger)

## Безопасность

- Не фиксировать реальные URL/хосты/учётные данные: использовать `<HOST>`, `<USER>`.
