# Навык: 1C (firm) — JSON-контракты

## Когда использовать

- Любая задача, где меняются JSON-схемы/пакеты обмена.
- Любая задача, где меняются HTTP API запросы/ответы (JSON).

## Источник (firm SoT)

- Правила JSON: [`json.md`](../../sources/1c-alfa/json.md)

## Ключевые требования (firm)

### 1) Запрет kebab-case

- Нельзя использовать `kebab-case` (дефисы) в именах полей JSON.

Основание: [`json.md#no-kebab-case`](../../sources/1c-alfa/json.md#no-kebab-case)

## Чеклист (что проверить)

- [ ] В именах полей JSON нет дефисов (`-`).
- [ ] Если интеграция затрагивает пакеты обмена — правила согласованы с моделью пакета.

## Evidence (как подтвердить)

- Пример JSON/схемы (санитизировано) или ссылка на артефакт в `<TICKET>`.
- Результат ревью (CR) или линтера/валидации схем.
