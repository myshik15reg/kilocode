# Навык: 1C (firm) — UI / управляемые формы

## Когда использовать

- Любая правка управляемых форм/UX.

## Источник (firm SoT)

- Приложение «Компоновка форм»: [`FORMS`](../../sources/1c-alfa/forms.md#checklist)

## Мини-чеклист (firm)

- Единый формат расположения заголовков однострочных полей/переключателей в пределах формы.

    - Основание: [`FORMS`](../../sources/1c-alfa/forms.md#forms-headings)

- Взаимосвязанные поля выравнивать по опорной линии.

    - Основание: [`FORMS`](../../sources/1c-alfa/forms.md#forms-alignment)

- Одни и те же элементы в разных формах называть одинаково и располагать примерно в одном месте.

    - Основание: [`FORMS`](../../sources/1c-alfa/forms.md#forms-consistency)

- Элемент, влияющий на другие элементы, располагать до зависимых.

    - Основание: [`FORMS`](../../sources/1c-alfa/forms.md#forms-dependencies)

- Табличная часть документа: ориентир — не менее 7 строк (оптимально — 10).
    - Основание: [`FORMS`](../../sources/1c-alfa/forms.md#forms-tabular-sections)
