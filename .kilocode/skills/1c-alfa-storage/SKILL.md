# Навык: 1C (firm) — Хранилище разработчиков

## Когда использовать

- Любая разработка в боевых конфигурациях, где используется хранилище.

## Источник (firm SoT)

- Раздел «Работа с хранилищами»: [`REG`](../../sources/1c-alfa/reg.md#storage)

## Ключевые правила (firm)

1. Перед разработкой рекурсивно получить все изменения из хранилища.

    - Основание: [`REG`](../../sources/1c-alfa/reg.md#storage)

2. Захватывать объекты на минимальное время; при возможности захватывать компонент, а не весь объект.

    - Основание: [`REG`](../../sources/1c-alfa/reg.md#storage)

3. Помещать изменения пакетно в рамках одной заявки `<TICKET>`.

    - Основание: [`REG`](../../sources/1c-alfa/reg.md#storage)

4. Перед помещением выполнить «Проверка модулей», без ошибок.
    - Основание: [`REG`](../../sources/1c-alfa/reg.md#storage)
