# First Time Setup (Getting Started)

> Единая точка входа для новых пользователей AlfaFlowAI. Читай этот файл ПЕРВЫМ.
> Время чтения: 10-15 минут.

## Что такое AlfaFlowAI?

AlfaFlowAI — это фреймворк качества для AI-агентов. Он обеспечивает:

- **Протоколы** — изолированный контекст для каждой задачи
- **Memory Bank** — долговременная память проекта
- **Quality Gates** — 100% coverage, lint clean, TDD
- **Multi-Agent** — координация специализированных агентов

---

## 5-Minute Quick Start

### Шаг 1: Подтверди прочтение (обязательно)

```
[MB: OK]
```

Выведи эту строку после прочтения `.kilocode/memory-bank/index.md`.

### Шаг 2: Создай протокол (для ЛЮБОЙ задачи)

```
/protocol-new.md
```

### Шаг 3: Работай по плану

- Обновляй `.protocols/.../plan.md` после каждого шага
- Записывай решения в `.protocols/.../execution.md`

### Шаг 4: Проверь качество

- 100% coverage (lines/branches/functions)
- 0 lint errors, 0 warnings
- Все тесты зелёные

### Шаг 5: Закрой протокол

```
/protocol-review-merge.md
```

## Варианты установки

### Вариант A: Embed (для одного проекта)

Просто скопируй `.kilocode/` в корень проекта:

```powershell
Copy-Item -Recurse path/to/workflowai/.kilocode ./
```

**Когда использовать:**

- Один проект
- Нужна полная переносимость
- Проект будет передан другой команде

### Вариант B: Global (для многих проектов)

Установи глобально (см. `/global-install.md`).

Пути по умолчанию:

- Unix: `~/.kilocode/` (pack: `~/.kilocode/workflowai/`)
- PowerShell: `$HOME/.kilocode/` (pack: `$HOME/.kilocode/workflowai/`)

**Когда использовать:**

- 3+ проектов на одной машине
- Команда разработки с единым стандартом
- Экономия места (один пакет на все проекты)

### Decision Matrix

| Критерий                 | Embed             | Global             |
| ------------------------ | ----------------- | ------------------ |
| Один проект              | **Рекомендуется** | OK                 |
| Много проектов           | Избыточно         | **Рекомендуется**  |
| Передача проекта         | **Рекомендуется** | Требует настройки  |
| Обновления пакета        | Вручную в каждом  | Один раз глобально |
| Windows без PowerShell 7 | **Рекомендуется** | Может не работать  |

## Критические правила (Zero Tolerance)

### 1. No Protocol, No Code

Любые изменения кода требуют протокола. **Без исключений.**

### 2. Memory First

Всегда начинай с `.kilocode/memory-bank/index.md` и подтверди `[MB: OK]`.

### 3. 100% Coverage

Tests: 100% lines, 100% branches, 100% functions. Build падает на меньшем.

### 4. Specialist First

Используй узкого специалиста (`react-dev`, `python-dev`) вместо общего `code`.

### 5. TDD

Тесты ПЕРЕД кодом. Red -> Green -> Refactor.

## Типичные ошибки новичков

| Ошибка                        | Почему плохо                   | Как правильно                     |
| ----------------------------- | ------------------------------ | --------------------------------- |
| Начать без `[MB: OK]`         | Потеря контекста, галлюцинации | Всегда читай Memory Bank первым   |
| Код без протокола             | Нет traceability, хаос         | Создай протокол даже для "мелочи" |
| Использовать `code` для React | Лишний контекст, менее точно   | Используй `react-dev`             |
| Пропустить тесты              | Технический долг растёт        | TDD: тест перед кодом             |
| Merge без review              | Баги в production              | Всегда через `reviewer`           |
