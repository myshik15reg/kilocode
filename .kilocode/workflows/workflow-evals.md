# Workflow: workflow-evals

## Goal

Задать минимальный набор сценариев, по которым проверяется маршрутизация и согласованность самого workflow-pack.

## How to use

1. Pick the scenario closest to the task.
2. Walk the route only through current SoT docs.
3. Compare expected mode, workflow entry, and bridge skill against the observed route.
4. If route or output is ambiguous, record the gap in protocol/evidence.
5. Re-run after doc updates.
