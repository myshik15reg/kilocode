# 1C (firm): Документирование HTTP-сервисов в Swagger (1c-alfa-http-swagger)

## Назначение

Обеспечить документирование новых HTTP-сервисов через подсистему «Работа со Swagger» (УЗ) для автоматической публикации.

## Источник (firm SoT)

- Требование и порядок описания: [`REG`](../sources/1c-alfa/reg.md#http-swagger)

## Процесс (firm)

1. При разработке нового HTTP-сервиса — выполнить описание через подсистему «Работа со Swagger» (УЗ).
2. В зависимости от конфигурации (ERP/CRM) — заполнить данные сервиса в табличной части элемента справочника «Корневой узел URL» (УЗ).
3. Указать методы и параметры методов сервиса.
4. Нажать «Обновить информацию по сервисам», чтобы публикация обновилась автоматически.

Основание: [`REG`](../sources/1c-alfa/reg.md#http-swagger)

## Плейсхолдеры

- URL/хосты не фиксировать в pack: использовать `<HOST>` и ссылки на SoT.
