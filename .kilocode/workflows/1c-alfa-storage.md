# 1C (firm): Совместное хранилище разработчиков (1C Storage) (1c-alfa-storage)

## Назначение

Стандартизировать работу разработчика с хранилищем 1С по фирменному регламенту.

## Источник (firm SoT)

- Работа с хранилищами: [`REG`](../sources/1c-alfa/reg.md#storage)

## Процесс (firm)

### 1) Перед началом разработки

- Рекурсивно получить все изменения из хранилища (работать с актуальной версией).

Основание: [`REG`](../sources/1c-alfa/reg.md#storage)

### 2) Захват объектов

- Захватывать объекты на минимальное время.
- Если меняется только компонент (модуль формы/макет/и т.п.) — захватывать компонент, а не весь объект.

Основание: [`REG`](../sources/1c-alfa/reg.md#storage)

### 3) Помещение изменений

- Помещать изменения пакетно в рамках одной заявки `<TICKET>`.
- При помещении заполнить:
    - **Метка**: `<TICKET>`
    - **Комментарий**: краткое описание для релиза

Основание: [`REG`](../sources/1c-alfa/reg.md#storage)

### 4) Проверка модулей перед помещением

- Выполнить «Конфигурация → Проверка модулей».
- Результат не должен содержать ошибок.

Основание: [`REG`](../sources/1c-alfa/reg.md#storage)
