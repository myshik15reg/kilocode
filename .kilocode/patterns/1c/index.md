## Quick Reference

### jdocstring

```bsl
/// @description Описание функции
/// @param {Тип} Параметр - Описание
/// @returns {Тип} Описание
/// @task <TICKET>
Функция МояФункция(Параметр) Экспорт
```

### Комментарии к изменениям

**Firm-SoT:** обязателен формат `+/- Альфа-Лизинг` при модификации существующего кода.

- Источник: [`REG`](../../sources/1c-alfa/reg.md#coding-standards-change-comments)

```bsl
// + Альфа-Лизинг. <USER>. <DATETIME>. <TICKET>.
// Описание изменений
НовыйКод();
// - Альфа-Лизинг. <USER>. <DATETIME>.
```

### Именование объектов

**Firm-SoT:**

- Новые объекты метаданных (и новые элементы при изменении объектов поставщика) префиксуются `ал_`.
    - Источник: [`REG`](../../sources/1c-alfa/reg.md#coding-standards-prefixes)
- Устаревшие объекты: префикс «Удалить».
    - Источник: [`REG`](../../sources/1c-alfa/reg.md#coding-standards-prefixes)

```
Новые объекты: ал_ИмяОбъекта
Синоним: Имя Объекта (БЕЗ префикса!)
Устаревшие: Удалить<ИмяОбъекта>
```

### RabbitMQ очереди

> ⚠️ Non-firm (до извлечения фирменных источников). Не считать firm-стандартом.

```
queue.from.<producer>.to.<consumer>.<objectType>.<event>
```

### RabbitMQ routing keys

> ⚠️ Non-firm (до извлечения фирменных источников). Не считать firm-стандартом.

```
<objectType>.<commandType>.<event>
```
