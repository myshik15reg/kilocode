# Отключаемый функционал

- [MUST] Предлагается её использовать в тех случаях, когда необходимо иметь возможность отключать тот или иной участок кода непосредственно из режима предприятия, без использования динамических обновлений, а также использовать вместо констант, значений предопределенных элементов, если это уместно и в тех случаях, когда эти объекты (константы и значения) используются также для отключения какого-либо участка кода. (section: Отключаемый функционал)
- [MUST] При желании использовать данную функцию, необходимо в первый параметр добавить строкой номер заявки из УЗ (без лидирующих нулей). Второй параметр отвечает за активацию по умолчанию: не заполнили или проставили - ЛОЖЬ, функционал не будет активен после релиза, заполнили - ИСТИНА, активация будет автоматически. Также активацию функционала можно настроить в соответствующем справочнике в режиме предприятия: (section: Отключаемый функционал)
