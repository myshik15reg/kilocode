# Подсистема Получение сообщений из очередей (RMQ) (применимо для конфигураций CRM, БП)

- [SHOULD] При запуске регламентного задания "Обработка сообщений из очереди" происходит обработка записей регистра со статусом "К обработке". При возникновении ошибки устанавливается статус ">"Ошибка обработки сообщения", в ресурс "Ошибка" записывается описание ошибки - такие записи подлежат ручному разбору (для повторной обработки сообщения ему следует вручную изменить статус на "К обработке"). Если сообщение записи регистра обработано успешно, такой записи устанавливается статус "Обработано". (section: Подсистема Получение сообщений из очередей (RMQ) (применимо для конфигураций CRM, БП))
- [SHOULD] Для того, чтобы создать новое регламентное задание по получению/обработке сообщений следует: (section: Подсистема Получение сообщений из очередей (RMQ) (применимо для конфигураций CRM, БП))
- [MUST] - При необходимости указать в списке "Назначенные очереди" количество сообщений, которое будет получаться из очереди/обрабатываться из регистра за один запуск рег. задания (section: Подсистема Получение сообщений из очередей (RMQ) (применимо для конфигураций CRM, БП))
