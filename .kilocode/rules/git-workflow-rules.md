# Git Workflow Rules (Conventional Commits + PR flow)

Source of Truth: [`git-workflow/SKILL.md`](../skills/git-workflow/SKILL.md:1) and [`rules-code/git-workflow.md`](../rules-code/git-workflow.md:1).

Minimal rules:

1. Work MUST be done via branches and PR; direct pushes to `main` MUST NOT be used.
2. Commits SHOULD follow Conventional Commits.
3. Merge MUST be blocked unless quality gates pass. See [`quality-gates.md`](quality-gates.md:1).
