# Testing Rules (TDD + 100% coverage)

Source of Truth: [`testing-detailed/SKILL.md`](../skills/testing-detailed/SKILL.md:1).

1. TDD MUST follow Red -> Green -> Refactor.
2. Coverage MUST be 100% (lines/branches/functions).
3. Tests MUST be deterministic; flaky tests MUST NOT be merged.
