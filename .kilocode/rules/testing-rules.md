# Testing Rules (TDD + 100% coverage)

> Этот файл — короткая обёртка для стабильных ссылок в документации.
> **Source of truth:** skill `/testing-detailed` (см. `.kilocode/skills/testing-detailed/SKILL.md`).

## Коротко (обязательно)

- **TDD обязателен:** Red → Green → Refactor.
- **Coverage обязателен:** 100% lines/branches/functions.
- Тесты должны быть детерминированными; flaky тесты запрещены.
