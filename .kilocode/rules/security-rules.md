# Security Rules (OWASP mindset)

Source of Truth: [`security-audit/SKILL.md`](../skills/security-audit/SKILL.md:1) and [`security.md`](../patterns/security/security.md:1).

Minimal non-negotiables:

1. Secrets MUST NOT be committed or logged.
2. Changes MUST be reviewed with OWASP Top 10 mindset.
3. Dependencies SHOULD be scanned and updated by a controlled process.
