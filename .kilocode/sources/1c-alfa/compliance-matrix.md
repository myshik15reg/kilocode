# 1C Alfa (firm): матрица соответствия требований (SoT)

Назначение: обеспечить трассируемость **«требование → источник (read-only, вне репозитория) → стабильный путь (SoT)»**.

Ограничения:

- Оригинальные документы (DOC/DOCX) не хранятся в репозитории.
- Ссылки на `temp/` не используются.
- Секреты/URL/учётные данные/ПДн не фиксируются; используются плейсхолдеры `<HOST>`, `<USER>`, `<TICKET>`.
