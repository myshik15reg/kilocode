# Security Rules (OWASP mindset)

> Этот файл — короткая обёртка для стабильных ссылок в документации.
> **Source of truth:** skill `/security-audit` и security patterns.

## Коротко (минимум для любого проекта)

- Думай категориями OWASP Top 10 (аутентификация/авторизация, инъекции, XSS, секреты, зависимости).
- Секреты — никогда не коммитить и не логировать.
- Зависимости — регулярно сканировать и обновлять.
