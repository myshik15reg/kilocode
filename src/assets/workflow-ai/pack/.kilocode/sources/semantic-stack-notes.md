# Semantic stack (входной контекст заказчика) — конспект терминов

> В этом репозитории AlfaFlowAI данный стек не является частью инфраструктуры pack.
> Конспект добавлен для единообразных ссылок в ADR/decision memo.

## Компоненты (как обозначено во входном контексте)

- `bge-m3` — модель эмбеддингов (multilingual), используется для построения векторных представлений.
- `Qdrant` — векторное хранилище (vector DB) для поиска по эмбеддингам.
- `bge-rerank` — reranker-модель для переранжирования результатов поиска (обычно по паре запрос-документ).
- `Neo4j` — графовая БД для представления и запросов по графу знаний/связям (например, зависимости, сущности, связи).

## Типовые задачи, которые покрывает retrieval-стек

- Семантический поиск по большому корпусу (код, docs, тикеты, решения) с контролем recall/precision.
- Быстрый “срез” релевантных фрагментов под конкретный вопрос/задачу.
- Использование графа знаний для:
    - навигации по зависимостям,
    - трассировки влияния,
    - дедупликации сущностей (объекты метаданных, термины, интеграции).
