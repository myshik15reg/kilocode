# Контекст продукта

## Назначение
Дать переиспользуемый пакет рабочих процессов, который стандартизирует то, как ИИ-агенты планируют, реализуют, тестируют и проводят ревью работы в проектах Kilo Code.

## Ключевые возможности
- `AGENTS.md` + `rules/`, `patterns/`, `workflows/` как единый источник истины.
- Memory Bank для стабильного, проектного контекста.
- Система протоколов (`brief.md`, `plan.md`, `execution.md`) для каждой задачи.
- PowerShell-скрипты для установки, инициализации, проверок целостности и создания протоколов.
- Шаблоны гейтов качества и рекомендации по включению их в CI/PR.

## UX-принципы
- Ясность важнее «хитрости» (явные шаги и чеклисты).
- Качество — исполняемое требование (без протокола — без кода; 100% покрытие).
- Низкая когнитивная нагрузка (шаблоны и скрипты вместо ручной настройки).
