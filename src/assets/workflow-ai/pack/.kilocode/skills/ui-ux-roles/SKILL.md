# UI/UX Roles

Use this skill when the task is primarily about interface behavior, usability, visual quality, or design-system consistency.

## Typical roles

| Need                 | Preferred role                                |
| -------------------- | --------------------------------------------- |
| UI implementation    | UI-focused dev or frontend specialist         |
| UX reasoning         | UI/UX or product-oriented specialist          |
| visual review        | reviewer or visual QA path                    |
| accessibility checks | accessibility-aware UI specialist or reviewer |

## Core rules

1. Separate visual polish from functional correctness.
2. Treat accessibility and interaction quality as first-class concerns when relevant.
3. Keep design-system consistency visible in scope and review.
4. Do not route pure backend or infrastructure work through UI/UX roles.
