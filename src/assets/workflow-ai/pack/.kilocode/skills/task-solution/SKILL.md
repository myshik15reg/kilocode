# Task Solution

Use this skill when a task needs a concrete solution shape before or during implementation.

## Goal

Turn an abstract request into a scoped, explainable solution path.

## Process

1. Define the real problem being solved.
2. Identify constraints, risks, and out-of-scope boundaries.
3. Choose the simplest solution that satisfies the task.
4. Make the expected outcome measurable.
5. Keep implementation details proportional to the task size.

## Good solution qualities

- clearly scoped
- aligned with the protocol or request
- realistic to verify
- minimal enough to avoid accidental redesign
- explicit about assumptions and tradeoffs

## Anti-patterns

- solving a larger problem than requested
- hiding risky assumptions
- mixing design, implementation, and future ideas into one vague answer
- producing a solution that cannot be verified
