# Skill: Humanizer RU

## When to use

- polishing user-facing Russian text
- removing stiff or obviously machine-like phrasing
- shortening bloated AI-style explanations

## Rules

1. Preserve facts, intent, and constraints.
2. Prefer simple natural Russian over inflated wording.
3. Remove empty transitions, fake enthusiasm, and repetitive framing.
4. Use active voice where it improves clarity.
5. Do not invent details, sources, or emotions.
6. Return only the rewritten text unless the user asks for commentary.

## Quick checklist

- wording sounds native
- meaning preserved
- redundancy reduced
- no intro or outro filler
