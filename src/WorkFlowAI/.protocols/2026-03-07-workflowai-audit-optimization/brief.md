# Brief

## Goal

Провести аудит `WorkFlowAI` и внести точечные улучшения, которые уменьшают когнитивную и токеновую нагрузку, повышают автономность, ускоряют вход в контекст и снижают риск дрейфа правил.

## Scope

- `AGENTS.md`
- `README.md`
- высокочастотные entrypoints в `.kilocode/`
- protocol/evidence артефакты текущей задачи

## Non-Goals

- Не менять фундаментальные quality gates пакета.
- Не переписывать весь pack целиком.
- Не трогать сторонние `third_party/` материалы.

## Acceptance Criteria

1. Есть документированный аудит с конкретными наблюдениями и рекомендациями.
2. Устранены хотя бы несколько реальных источников лишних токенов/дублирования.
3. Навигация и правила для старта стали короче и однозначнее без потери SoT.
4. Все изменённые ссылки и структура согласованы между собой.

## Definition of Done

- Создан protocol с brief/plan/execution.
- Внесены фокусные улучшения в документацию pack.
- Проведена проверка ссылок/поиском по изменённым местам.
- Итог содержит список изменений и оставшиеся рекомендации.
