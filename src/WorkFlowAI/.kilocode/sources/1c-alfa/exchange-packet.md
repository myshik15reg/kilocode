<a id="configuration"></a>
## Конфигурация пакетов (MUST)

**MUST:** Для хранения списка возможных моделей пакетов и их структуры служит конфигурация «ПакетОбмена». Строка подключения фиксируется в документации как `Srvr="<HOST>";Ref="<REF>"`.

**MUST:** Каждой модели (поле `model` пакета обмена) соответствует справочник или документ конфигурации.

**MUST:** Все объекты метаданных, которым соответствует модель обмена, должны быть включены в подсистему «ОбъектыОбмена».

Источник:
- `7.+Описание+обменов+RabbitMQ.doc`, «Пакет обмена» → «Конфигурация пакетов»
- `Описание_обмена.doc`, «Пакет обмена» → «Конфигурация пакетов»

<a id="model-mapping"></a>
## Соответствие реквизитов модели объектам 1С (MUST)

**MUST:** Каждому реквизиту объекта‑модели соответствует поле модели обмена.

**MUST:** Если поле пакета имеет тип массива, то в соответствующем объекте создаётся табличная часть со списком свойств.

**MUST:** Ограничение: нельзя использовать вложенные массивы (в 1С нельзя создать вложенные табличные части).

**MUST:** Всем полям объекта‑модели устанавливается тип «строка неограниченной длины».

Источник:
- `7.+Описание+обменов+RabbitMQ.doc`, «Пакет обмена» → «Конфигурация пакетов»
- `Описание_обмена.doc`, «Пакет обмена» → «Конфигурация пакетов»

<a id="load-algorithm"></a>
## Алгоритм загрузки пакета обмена (MUST)

**MUST:** В общем случае обработка полученного пакета обмена должна приводить к созданию (обновлению) объекта в системе 1С; обработка выполняется в несколько этапов.

Источник:
- `7.+Описание+обменов+RabbitMQ.doc`, «Пакет обмена» → «Алгоритм загрузки пакета обмена»
- `Описание_обмена.doc`, «Пакет обмена» → «Алгоритм загрузки пакета обмена»
