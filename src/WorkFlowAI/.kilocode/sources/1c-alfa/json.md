# JSON (firm): правила для обменов и HTTP

Это **не** копия первичного документа. Это санитизированная выжимка правил по JSON‑контрактам (обмены и HTTP), используемая в pack как firm‑SoT.

Плейсхолдеры:
- `<HOST>` — хост/URL (в pack реальные адреса не фиксируются).

## Требования (MUST)

<a id="no-kebab-case"></a>
### Именование полей JSON

**MUST:** Нельзя использовать `kebab-case` (дефисы в именах полей). Причина: неудобно для чтения и «ручного» составления классов, многие языки не поддерживают дефисы в идентификаторах — это приводит к лишнему коду.

Источник:
- `Описание+JSON+при+обменах.doc`, «Содержимое JSON»
