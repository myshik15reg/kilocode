# Anti-Patterns

Use this skill as a quick reminder of what not to do in normal workflow execution.

## High-value mistakes to avoid

1. Changing a repository without the required protocol flow.
2. Skipping Memory Bank on non-trivial work.
3. Using a broad fallback mode when a narrower specialist exists.
4. Delegating with vague context or without a measurable goal.
5. Treating assumptions as facts.
6. Expanding a small task into an unrelated redesign.
7. Shipping verification claims without real evidence.

## Practical checks

Before moving forward, ask:

- am I following the correct protocol path?
- did I load only the context actually needed?
- is there a narrower specialist for this task?
- are my claims source-backed?
- is the diff still aligned with the user's request?

## Use with

- mode selection
- orchestration and handoff
- quick-fix vs deeper workflow choices
- testing and review gates
