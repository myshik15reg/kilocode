# First Time Setup

Purpose: give a new user or agent the shortest safe path into AlfaFlowAI.

## Quick start

1. Read [`../../AGENTS.md`](../../AGENTS.md:1).
2. Read [`../QUICK.md`](../QUICK.md:1).
3. Read the workspace Memory Bank index: [`../memory-bank/index.md`](../memory-bank/index.md:1).
4. Confirm readiness with `[MB: OK]`.
5. If the task changes the repository, start with [`protocol-new.md`](protocol-new.md:1).
6. Use [`quickref.md`](quickref.md:1) as the operational menu.

## What this system gives you

- a startup corridor
- a Memory Bank structure for long-lived context
- protocol workflows for task-local execution
- mode routing and delegation rules
- quality-gate and review flows

## Avoid these mistakes

- changing the repo without a protocol
- skipping Memory Bank on non-trivial work
- using a broad fallback mode when a specialist exists
- treating template files as live workspace state
