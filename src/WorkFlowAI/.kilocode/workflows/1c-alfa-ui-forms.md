# 1C (firm): UI / управляемые формы — компоновка (чеклист) (1c-alfa-ui-forms)

## Назначение
Дать быстрый чеклист компоновки управляемых форм в соответствии с фирменным приложением к регламенту.

## Источник (firm SoT)
- Приложение «Компоновка форм»: [`FORMS`](../sources/1c-alfa/forms.md#checklist)

## Чеклист (firm)

### 1) Единообразие заголовков
- Внутри одной формы заголовки для однострочных полей ввода/переключателей/тумблеров располагать одинаково: **или слева, или сверху**.

Основание: [`FORMS`](../sources/1c-alfa/forms.md#forms-headings)

### 2) Выравнивание взаимосвязанных полей
- Поля взаимосвязанных реквизитов в одной группе выравнивать по опорной линии.

Основание: [`FORMS`](../sources/1c-alfa/forms.md#forms-alignment)

### 3) Согласованность по системе
- Элементы, которые в разных формах выполняют одну функцию, называть одинаково и располагать примерно в одном месте.

Основание: [`FORMS`](../sources/1c-alfa/forms.md#forms-consistency)

### 4) Порядок зависимостей
- Элемент, который влияет на другие элементы, располагать до зависимых (выше/левее).

Основание: [`FORMS`](../sources/1c-alfa/forms.md#forms-dependencies)

### 5) Группировка в форме документа
- В шапке: левая/правая колонки заполняются по признакам «важные/обязательные/ручной ввод» vs «вспомогательные/чаще авто/необязательные».

Основание: [`FORMS`](../sources/1c-alfa/forms.md#forms-grouping)

### 6) Табличные части
- Табличная часть документа: ориентир — **не менее 7 строк** (оптимально — не менее 10). Если < 7 — рекомендуется отдельная вкладка.

Основание: [`FORMS`](../sources/1c-alfa/forms.md#forms-tabular-sections)
