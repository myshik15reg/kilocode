# Workflow: styleguide

## Goal

Keep formatting and stylistic guidance consistent without duplicating repository-specific coding rules.

## Core rules

1. Follow the consuming repository's style rules first.
2. Prefer consistency with nearby code over abstract purity.
3. Keep style changes out of unrelated tasks unless they are part of the requested fix.
4. Avoid broad cosmetic churn with little user value.

## Use when

- a task explicitly involves style cleanup
- a new document or example needs consistent formatting
- maintainers need a compact reminder of style discipline
