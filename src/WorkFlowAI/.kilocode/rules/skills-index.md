# Skills Usage

Purpose: remind agents to reuse an existing skill before inventing a new local process.

## Rules

1. Check whether an appropriate skill already exists before creating new instructions.
2. If a matching skill exists, follow its `SKILL.md`.
3. If no suitable skill exists and the pattern is reusable, create one through [`../workflows/create-new-skill.md`](../workflows/create-new-skill.md:1).
4. Keep skills task-focused and portable.
