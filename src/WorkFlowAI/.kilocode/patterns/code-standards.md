# Code Standards

Purpose: provide a compact index to general coding principles without duplicating large rulebooks.

## Core principles

- keep solutions simple and scoped
- prefer clarity over cleverness
- align verification with risk
- keep public behavior and contracts explicit
- avoid introducing unnecessary technical debt

## Use with

- language-specific patterns
- repository testing and quality rules
- project-specific coding conventions from the consuming workspace
