## 1. Language Overview

### 1.1 История и контекст

**1C:Enterprise Script Language (BSL)** - встроенный скриптовый язык платформы 1С:Предприятие 8.3, используемый для разработки бизнес-приложений. Язык создан компанией "1С" специально для российского рынка и имеет ряд уникальных особенностей:

- **Год появления:** 2001 (версия 1С:Предприятие 8.0)
- **Текущая версия платформы:** 8.3 (активно развивается с 2012 года)
- **Парадигма:** Процедурный, с элементами ООП
- **Типизация:** Динамическая, слабая
- **Расширения файлов:** `.bsl` (EDT формат), `.1s` (классический формат)

### 1.2 Основные концепции языка

#### 1.2.1 Регистронезависимость

**Критически важная особенность:** Язык 1С **полностью регистронезависимый**. Все следующие варианты эквивалентны:

```1c
Процедура = процедура = ПРОЦЕДУРА = ПрОцЕдУрА
Если = если = ЕСЛИ = ЕсЛи
КонецПроцедуры = конецпроцедуры = КОНЕЦПРОЦЕДУРЫ
```

Это создает уникальные вызовы для Tree-sitter грамматики, так как стандартный механизм распознавания ключевых слов чувствителен к регистру.

#### 1.2.2 Билингвальность

Язык поддерживает **два набора ключевых слов**: русский и английский, которые могут быть смешаны в одном файле:

**Русские ключевые слова:**
```1c
Процедура МояПроцедура()
    Если Истина Тогда
        Сообщить("Привет");
    КонецЕсли;
КонецПроцедуры
```

**Английские ключевые слова:**
```1c
Procedure MyProcedure()
    If True Then
        Message("Hello");
    EndIf;
EndProcedure
```

**Смешанный стиль (допустимо):**
```1c
Procedure МояПроцедура()
    Если True Then
        Сообщить("Привет");
    EndIf;
EndProcedure
```

#### 1.2.3 Кириллица в идентификаторах

Идентификаторы (имена переменных, процедур, функций) могут содержать кириллические символы:

```1c
Перем МояПеременная;
Перем СчетчикЭлементов;

Функция ПолучитьСуммуПродаж()
    // ...
КонецФункции
```

#### 1.2.4 Модульность и область видимости

Код 1С организован в **модули**:

- **Общие модули** - переиспользуемый код
- **Модули объектов** - логика документов, справочников
- **Модули форм** - обработка событий интерфейса
- **Модули команд** - команды пользователя
- **Модули менеджеров** - управление объектами метаданных

**Модификаторы видимости:**
- `Экспорт` / `Export` - публичный метод/переменная
- Без модификатора - приватный метод/переменная

#### 1.2.5 Клиент-серверная архитектура

Код может выполняться в разных контекстах:

**Аннотации контекста выполнения:**
```1c
&НаКлиенте              // &AtClient - выполняется на стороне клиента
&НаСервере              // &AtServer - выполняется на стороне сервера
&НаСервереБезКонтекста  // &AtServerNoContext - серверный вызов без контекста
&НаКлиентеНаСервереБезКонтекста // Универсальный код
```

### 1.3 Отличия от других языков

| Характеристика | 1C BSL | JavaScript | Python | Pascal |
|----------------|--------|------------|--------|--------|
| Регистр ключевых слов | Нечувствителен | Чувствителен | Чувствителен | Нечувствителен |
| Кириллица в идентификаторах | ✅ Да | ❌ Нет | ✅ Да (с Python 3) | ❌ Нет |
| Билингвальные ключевые слова | ✅ Да (RU/EN) | ❌ Нет | ❌ Нет | ❌ Нет |
| Явное указание конца блока | ✅ Да (`КонецЕсли`) | ❌ Нет (`}`) | ❌ Нет (отступы) | ✅ Да (`end`) |
| Типизация | Динамическая | Динамическая | Динамическая | Статическая |
| Препроцессор | ✅ Да (`#Если`) | ❌ Нет | ❌ Нет | ✅ Да (`{$IFDEF}`) |
| ООП | Частично (через метаданные) | ✅ Полное | ✅ Полное | ✅ Полное |

### 1.4 Специфичные возможности платформы 1С

#### 1.4.1 Метаданные

1С предоставляет доступ к объектам метаданных через специальный синтаксис:

```1c
// Доступ к справочнику
Справочники.Номенклатура
Catalogs.Products

// Создание элемента справочника
НовыйЭлемент = Справочники.Номенклатура.СоздатьЭлемент();

// Доступ к документу
Документы.ПоступлениеТоваров
Documents.GoodsReceipt

// Регистры
РегистрыСведений.ЦеныНоменклатуры
InformationRegisters.ProductPrices
```

#### 1.4.2 Язык запросов

Встроенный язык запросов (1C Query Language) для работы с базой данных:

```1c
Запрос = Новый Запрос;
Запрос.Текст = 
"ВЫБРАТЬ
|    Номенклатура.Ссылка КАК Ссылка,
|    Номенклатура.Наименование КАК Наименование,
|    Номенклатура.Артикул КАК Артикул
|ИЗ
|    Справочник.Номенклатура КАК Номенклатура
|ГДЕ
|    Номенклатура.ПометкаУдаления = ЛОЖЬ";

Результат = Запрос.Выполнить();
```

#### 1.4.3 Обработчики событий

Специальные процедуры с предопределенными именами для обработки событий:

```1c
// События документа
Процедура ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)
    // Код выполняется перед записью документа
КонецПроцедуры

Процедура ПриЗаписи(Отказ)
    // Код выполняется при записи
КонецПроцедуры

// События формы
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
    // Инициализация формы на сервере
КонецПроцедуры

// События реквизита
Процедура НоменклатураПриИзменении(Элемент)
    // Обработка изменения реквизита
КонецПроцедуры
```

#### 2.1.2 Стратегия регистронезависимости

Для Tree-sitter грамматики необходимо создать helper функцию `caseInsensitive`, которая генерирует regex для регистронезависимого сопоставления:

```javascript
function caseInsensitive(keyword) {
  return new RegExp(
    keyword
      .split('')
      .map(char => {
        // Для кириллицы
        if (/[а-яА-ЯёЁ]/.test(char)) {
          return `[${char.toLowerCase()}${char.toUpperCase()}]`;
        }
        // Для латиницы
        if (char.toLowerCase() === char.toUpperCase()) {
          return char;
        }
        return `[${char.toLowerCase()}${char.toUpperCase()}]`;
      })
      .join('')
  );
}

// Пример использования:
// caseInsensitive('Процедура') -> /[пП][рР][оО][цЦ][еЕ][дД][уУ][рР][аА]/
// caseInsensitive('Procedure') -> /[pP][rR][oO][cC][eE][dD][uU][rR][eE]/
```

### 2.2 Declarations (Объявления)

#### 2.2.1 Процедуры (Procedures)

Процедура - подпрограмма, которая не возвращает значение.

**Синтаксис:**
```
Процедура <Имя>([<Параметры>]) [Экспорт]
    [<Тело процедуры>]
КонецПроцедуры
```

**Примеры:**

```1c
// Простая процедура без параметров
Процедура ПростаяПроцедура()
    Сообщить("Привет, мир!");
КонецПроцедуры

// Процедура с параметрами
Процедура ВывестиСообщение(Текст, Уровень = "Информация")
    Если Уровень = "Ошибка" Тогда
        Сообщить(Текст, СтатусСообщения.Важное);
    Иначе
        Сообщить(Текст);
    КонецЕсли;
КонецПроцедуры

// Экспортная процедура (публичная)
Процедура ОбновитьДанные(Объект) Экспорт
    Объект.Записать();
КонецПроцедуры

// Процедура с аннотацией контекста
&НаСервере
Процедура ОбновитьДанныеНаСервере()
    // Серверная логика
КонецПроцедуры
```

#### 2.2.2 Функции (Functions)

Функция - подпрограмма, которая возвращает значение.

**Синтаксис:**
```
Функция <Имя>([<Параметры>]) [Экспорт]
    [<Тело функции>]
    [Возврат <Значение>;]
КонецФункции
```

**Примеры:**

```1c
// Простая функция
Функция ПолучитьТекущуюДату()
    Возврат ТекущаяДата();
КонецФункции

// Функция с параметрами
Функция Сложить(А, Б)
    Возврат А + Б;
КонецФункции

// Функция с параметрами по умолчанию
Функция ФорматироватьЧисло(Число, Разрядов = 2)
    Возврат Формат(Число, "ЧЦ=" + Разрядов);
КонецФункции

// Экспортная функция
Функция ПолучитьВерсиюКонфигурации() Экспорт
    Возврат Метаданные.Версия;
КонецФункции

// Функция с аннотацией
&НаКлиентеНаСервереБезКонтекста
Функция ПустаяСтрока(Строка)
    Возврат НЕ ЗначениеЗаполнено(Строка);
КонецФункции
```

#### 2.2.3 Параметры функций и процедур

**Типы параметров:**

1. **Обязательные параметры**
```1c
Функция Умножить(А, Б)
    Возврат А * Б;
КонецФункции
```

2. **Необязательные параметры (с значением по умолчанию)**
```1c
Функция Степень(Число, Степень = 2)
    Возврат Число ^ Степень;
КонецФункции

// Вызов:
Степень(5);      // Вернет 25 (5^2)
Степень(5, 3);   // Вернет 125 (5^3)
```

3. **Параметры по значению (Val)**
```1c
Процедура Пример(Знач Параметр)
    // Параметр передан по значению, изменения не влияют на оригинал
    Параметр = Параметр + 1;
КонецПроцедуры
```

4. **Смешанные параметры**
```1c
Функция СложнаяФункция(Обязательный1, Обязательный2, Знач Копия, Необязательный = 10)
    // Обработка параметров
    Возврат Обязательный1 + Обязательный2 + Копия + Необязательный;
КонецФункции
```

#### 2.2.4 Переменные (Variables)

**Синтаксис:**
```
Перем <Имя> [Экспорт];
```

**Примеры:**

```1c
// Модульная переменная
Перем СчетчикВызовов;

// Экспортная переменная (публичная)
Перем МаксимальноеКоличество Экспорт;

// Несколько переменных в одной строке (не рекомендуется, но допустимо)
Перем А, Б, В;

// Локальная переменная (внутри процедуры/функции)
Процедура Пример()
    Перем ЛокальнаяПеременная;
    ЛокальнаяПеременная = 10;
    
    // Или можно без объявления (неявное объявление)
    АвтоматическаяПеременная = 20;
КонецПроцедуры
```

**Область видимости:**
- Модульные переменные (объявлены в начале модуля) - доступны во всех процедурах/функциях модуля
- Локальные переменные - доступны только внутри процедуры/функции
- Экспортные переменные - доступны из других модулей

### 2.3 Statements (Операторы)

#### 2.3.1 Условные операторы

##### Если-Тогда-Иначе (If-Then-Else)

**Синтаксис:**
```
Если <Условие> Тогда
    <Операторы>
[ИначеЕсли <Условие> Тогда
    <Операторы>]
[Иначе
    <Операторы>]
КонецЕсли;
```

**Примеры:**

```1c
// Простое условие
Если Возраст >= 18 Тогда
    Сообщить("Совершеннолетний");
КонецЕсли;

// Условие с альтернативой
Если Температура > 0 Тогда
    Сообщить("Тепло");
Иначе
    Сообщить("Холодно");
КонецЕсли;

// Множественные условия
Если Оценка >= 90 Тогда
    Результат = "Отлично";
ИначеЕсли Оценка >= 70 Тогда
    Результат = "Хорошо";
ИначеЕсли Оценка >= 50 Тогда
    Результат = "Удовлетворительно";
Иначе
    Результат = "Неудовлетворительно";
КонецЕсли;

// Вложенные условия
Если ПользовательИмеетПрава Тогда
    Если ДанныеКорректны Тогда
        ВыполнитьОперацию();
    Иначе
        Сообщить("Данные некорректны");
    КонецЕсли;
Иначе
    Сообщить("Недостаточно прав");
КонецЕсли;
```

#### 2.3.2 Циклы

##### Цикл Для Каждого (For Each)

**Синтаксис:**
```
Для Каждого <Переменная> Из <Коллекция> Цикл
    <Операторы>
    [Прервать;]
    [Продолжить;]
КонецЦикла;
```

**Примеры:**

```1c
// Итерация по массиву
Массив = Новый Массив;
Массив.Добавить(1);
Массив.Добавить(2);
Массив.Добавить(3);

Для Каждого Элемент Из Массив Цикл
    Сообщить(Элемент);
КонецЦикла;

// Итерация по строкам табличной части
Для Каждого СтрокаТовары Из Документ.Товары Цикл
    Сумма = СтрокаТовары.Количество * СтрокаТовары.Цена;
    СтрокаТовары.Сумма = Сумма;
КонецЦикла;

// Использование Прервать
Для Каждого Товар Из СписокТоваров Цикл
    Если Товар.Наименование = "Искомый" Тогда
        НайденныйТовар = Товар;
        Прервать; // Выход из цикла
    КонецЕсли;
КонецЦикла;

// Использование Продолжить
Для Каждого Элемент Из Коллекция Цикл
    Если НЕ Элемент.Активный Тогда
        Продолжить; // Пропустить текущую итерацию
    КонецЕсли;
    ОбработатьЭлемент(Элемент);
КонецЦикла;
```

##### Цикл Для (For)

**Синтаксис:**
```

```

**Примеры:**


##### Цикл Пока (While)

**Синтаксис:**
```

    <Операторы>
КонецЦикла;
```

**Примеры:**

```1c
// Простой цикл пока
Счетчик = 0;
Пока Счетчик < 10 Цикл
    Сообщить(Счетчик);
    Счетчик = Счетчик + 1;
КонецЦикла;

// Чтение файла до конца
ТекстовыйДокумент = Новый ТекстовыйДокумент;
ТекстовыйДокумент.Прочитать("файл.txt");

НомерСтроки = 1;
Пока НомерСтроки <= ТекстовыйДокумент.КоличествоСтрок() Цикл
    Строка = ТекстовыйДокумент.ПолучитьСтроку(НомерСтроки);
    ОбработатьСтроку(Строка);
    НомерСтроки = НомерСтроки + 1;
КонецЦикла;

// Цикл с условием выхода
Пока Истина Цикл
    Значение = ПолучитьСледующееЗначение();
    Если Значение = Неопределено Тогда
        Прервать;
    КонецЕсли;
    ОбработатьЗначение(Значение);
КонецЦикла;
```

### 2.4 Expressions (Выражения)

#### 2.4.1 Арифметические операции

**Операторы:**
- `+` - сложение
- `-` - вычитание
- `*` - умножение
- `/` - деление
- `%` - остаток от деления (модуль)

**Приоритет операций (от высшего к низшему):**
1. Унарный минус `-`
2. `*`, `/`, `%`
3. `+`, `-`

**Примеры:**

```1c
// Простые операции
Сумма = 10 + 5;           // 15
Разность = 10 - 5;        // 5
Произведение = 10 * 5;    // 50
Частное = 10 / 5;         // 2
Остаток = 10 % 3;         // 1

// Унарный минус
Отрицательное = -10;

// Сложные выражения
Результат = 2 + 3 * 4;    // 14 (сначала умножение)
Результат = (2 + 3) * 4;  // 20 (сначала скобки)

// Операции с переменными
А = 10;
Б = 20;
Сумма = А + Б;            // 30

// Инкремент через присваивание
Счетчик = Счетчик + 1;

// Составные выражения
ИтоговаяСумма = Количество * Цена * (1 - Скидка/100) * (1 + НДС/100);
```

#### 2.4.2 Логические операции

**Операторы:**
- `И` / `And` - логическое И
- `Или` / `Or` - логическое ИЛИ
- `Не` / `Not` - логическое НЕ

**Приоритет операций:**
1. `Не` / `Not`
2. `И` / `And`
3. `Или` / `Or`

**Примеры:**

```1c
// Простые логические операции
Результат = Истина И Ложь;        // Ложь
Результат = Истина ИЛИ Ложь;      // Истина
Результат = НЕ Истина;            // Ложь

// В условиях
Если Возраст >= 18 И ИмеетПаспорт Тогда
    Сообщить("Доступ разрешен");
КонецЕсли;

Если Админ ИЛИ Модератор Тогда
    ПоказатьАдминПанель();
КонецЕсли;

Если НЕ Заблокирован Тогда
    РазрешитьВход();
КонецЕсли;

// Сложные выражения
Если (Возраст >= 18 И ИмеетПаспорт) ИЛИ (Возраст >= 14 И ИмеетРазрешениеРодителей) Тогда
    РазрешитьДоступ();
КонецЕсли;

// Короткое вычисление (short-circuit evaluation)
Если ОбъектСуществует И Объект.Свойство > 0 Тогда
    // Объект.Свойство вычисляется только если ОбъектСуществует = Истина
КонецЕсли;
```

#### 2.4.3 Операции сравнения

**Операторы:**
- `=` - равно
- `<>` - не равно
- `>` - больше
- `<` - меньше
- `>=` - больше или равно
- `<=` - меньше или равно

**Примеры:**

```1c
// Сравнение чисел
Результат = 10 = 10;      // Истина
Результат = 10 <> 5;      // Истина
Результат = 10 > 5;       // Истина
Результат = 10 < 5;       // Ложь
Результат = 10 >= 10;     // Истина
Результат = 10 <= 5;      // Ложь

// Сравнение строк
Результат = "Привет" = "Привет";    // Истина
Результат = "А" < "Б";              // Истина (лексикографическое)

// Сравнение дат
Дата1 = Дата(2023, 1, 1);
Дата2 = Дата(2024, 1, 1);
Результат = Дата1 < Дата2;          // Истина

// Сравнение с Неопределено
Если Значение = Неопределено Тогда
    Сообщить("Значение не задано");
КонецЕсли;

// Регистронезависимое сравнение строк
Если ВРег(Строка1) = ВРег(Строка2) Тогда
    // Строки равны без учета регистра
КонецЕсли;
```

#### 2.4.4 Тернарный оператор (условное выражение)

```1c
// Вместо простого If-Then-Else
// Вместо:
```

```1c
// Выполнение на клиенте

КонецПроцедуры

// Выполнение на сервере

&НаКлиентеНаСервереБезКонтекста
Функция ПустаяСтрока(Значение)
    // Выполняется и на клиенте, и на сервере

КонецФункции
```

2. **Модификаторы расширений:**

```1c
КонецПроцедуры
```

#### 2.6.2 Директивы препроцессора

Препроцессор обрабатывается до компиляции кода.

**Синтаксис:**
```
#Если <Условие> Тогда
    <Код>
[#ИначеЕсли <Условие> Тогда
    <Код>]
[#Иначе
    <Код>]
#КонецЕсли
```

**Примеры:**

1. **Условная компиляция по контексту:**

```1c
#Если Сервер Тогда
    // Код только для сервера
    Процедура СерверныйМетод()
        // ...
    КонецПроцедуры
#Иначе
    // Код для клиента
    Процедура КлиентскийМетод()
        // ...
    КонецПроцедуры
#КонецЕсли
```

2. **Множественные условия:**

```1c
#Если Сервер Или ТолстыйКлиентОбычноеПриложение Или ВнешнееСоединение Тогда
    // Серверный код или толстый клиент
    Процедура ВыполнитьНаСервере()
        // ...
    КонецПроцедуры
#КонецЕсли

#Если Клиент Тогда
    // Код только для тонкого клиента
    Процедура КлиентскаяЛогика()
        // ...
    КонецПроцедуры
#КонецЕсли
```

3. **Проверка типа клиента:**

```1c
#Если ТонкийКлиент Тогда
    Сообщить("Работает тонкий клиент");
#ИначеЕсли ТолстыйКлиентОбычноеПриложение Тогда
    Сообщить("Работает толстый клиент");
#ИначеЕсли ВебКлиент Тогда
    Сообщить("Работает веб-клиент");
#КонецЕсли
```

4. **Области кода (Regions):**

```1c
#Область ПрограммныйИнтерфейс

// Публичные процедуры и функции
Процедура ПубличнаяПроцедура() Экспорт
    // ...
КонецПроцедуры

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

// Приватные процедуры и функции
Процедура ПриватнаяПроцедура()
    // ...
КонецПроцедуры

#КонецОбласти

#Область ОбработчикиСобытий

// Обработчики событий формы/объекта
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
    // ...
КонецПроцедуры

#КонецОбласти
```

**Доступные условия препроцессора:**
- `Сервер` - серверный код
- `Клиент` - клиентский код  
- `ТонкийКлиент` - тонкий клиент
- `ТолстыйКлиентОбычноеПриложение` - толстый клиент
- `ТолстыйКлиентУправляемоеПриложение` - управляемое приложение толстого клиента
- `ВебКлиент` - веб-клиент
- `ВнешнееСоединение` - внешнее соединение
- `МобильноеПриложениеКлиент` - мобильный клиент
- `МобильноеПриложениеСервер` - мобильный сервер

#### 2.6.3 Обработчики событий

Процедуры с предопределенными именами для обработки событий объектов и форм.

**Категории обработчиков:**

1. **События объекта (документы, справочники):**

```1c
// Перед записью объекта
Процедура ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)
    // Отказ - признак отказа от записи
    // РежимЗаписи - режим записи (Запись, Проведение, ОтменаПроведения)
    // РежимПроведения - режим проведения (Оперативный, Неоперативный)
    
    Если НЕ ЗначениеЗаполнено(Дата) Тогда
        Сообщить("Не заполнена дата документа");
        Отказ = Истина;
    КонецЕсли;
КонецПроцедуры

// При записи объекта
Процедура ПриЗаписи(Отказ)
    // Выполняется после успешной записи
КонецПроцедуры

// Перед удалением
Процедура ПередУдалением(Отказ)
    Если ЕстьЗависимыеДокументы() Тогда
        Сообщить("Нельзя удалить, есть зависимые документы");
        Отказ = Истина;
    КонецЕсли;
КонецПроцедуры

// При удалении
Процедура ПриУдалении(Отказ)
    // Выполняется при удалении
КонецПроцедуры

// При копировании
Процедура ПриКопировании(ОбъектКопирования)
    // ОбъектКопирования - объект-источник
    // Можно изменить данные копии
    Дата = ТекущаяДата();
КонецПроцедуры

// Обработка заполнения
Процедура ОбработкаЗаполнения(ДанныеЗаполнения, СтандартнаяОбработка)
    // Заполнение реквизитов при создании
    Если ТипЗнч(ДанныеЗаполнения) = Тип("СправочникСсылка.Контрагенты") Тогда
        Контрагент = ДанныеЗаполнения;
    КонецЕсли;
КонецПроцедуры
```

2. **События документа (проведение):**

```1c
// Обработка проведения
Процедура ОбработкаПроведения(Отказ, РежимПроведения)
    // Формирование движений документа
    Движения.ОстаткиТоваров.Записать = Истина;
    
    Для Каждого СтрокаТовары Из Товары Цикл
        Движение = Движения.ОстаткиТоваров.Добавить();
        Движение.ВидДвижения = ВидДвиженияНакопления.Приход;
        Движение.Период = Дата;
        Движение.Номенклатура = СтрокаТовары.Номенклатура;
        Движение.Количество = СтрокаТовары.Количество;
    КонецЦикла;
КонецПроцедуры

// Обработка отмены проведения
Процедура ОбработкаУдаленияПроведения(Отказ)
    // Действия при отмене проведения
КонецПроцедуры

// Обработка проверки заполнения
Процедура ОбработкаПроверкиЗаполнения(Отказ, ПроверяемыеРеквизиты)
    // Проверка обязательных реквизитов
    МассивНепроверяемых = Новый Массив;
    
    Если НЕ ТипОперации = Перечисления.ТипыОперацийПоступления.Покупка Тогда
        МассивНепроверяемых.Добавить("Поставщик");
    КонецЕсли;
    
    ОбщегоНазначения.УдалитьНепроверяемыеРеквизитыИзМассива(
        ПроверяемыеРеквизиты, МассивНепроверяемых);
КонецПроцедуры
```

3. **События формы:**

```1c
// Создание на сервере
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
    // Инициализация формы на сервере
    УстановитьВидимостьДоступность();
КонецПроцедуры

// При открытии
&НаКлиенте
Процедура ПриОткрытии(Отказ)
    // Действия при открытии формы на клиенте
КонецПроцедуры

// Перед закрытием
&НаКлиенте
Процедура ПередЗакрытием(Отказ, ЗавершениеРаботы, ТекстПредупреждения, СтандартнаяОбработка)
    Если Модифицированность Тогда
        Ответ = Вопрос("Данные были изменены. Сохранить?", 
            РежимДиалогаВопрос.ДаНетОтмена);
        
        Если Ответ = КодВозвратаДиалога.Да Тогда
            Записать();
        ИначеЕсли Ответ = КодВозвратаДиалога.Отмена Тогда
            Отказ = Истина;
        КонецЕсли;
    КонецЕсли;
КонецПроцедуры

// При закрытии
&НаКлиенте
Процедура ПриЗакрытии(ЗавершениеРаботы)
    // Освобождение ресурсов
КонецПроцедуры
```

4. **События реквизитов формы:**

```1c

    СтандартнаяОбработка = Ложь;

КонецПроцедуры

// Начало выбора
&НаКлиенте
Процедура ДоговорНачалоВыбора(Элемент, ДанныеВыбора, СтандартнаяОбработка)
    // Настройка параметров выбора
    СтандартнаяОбработка = Ложь;
    ПараметрыФормы = Новый Структура("Контрагент", Контрагент);

КонецПроцедуры

&НаКлиенте
Процедура СкидкаОчистка(Элемент, СтандартнаяОбработка)
    // Обработка очистки значения
    ПересчитатьСумму();
КонецПроцедуры

// Автоподбор
&НаКлиенте
Процедура НоменклатураАвтоПодбор(Элемент, Текст, ДанныеВыбора, Ожидание, СтандартнаяОбработка)
    // Настройка автоподбора
    Если НЕ Ожидание И ЗначениеЗаполнено(Текст) Тогда
        СтандартнаяОбработка = Ложь;
        ДанныеВыбора = ПолучитьСписокНоменклатуры(Текст);
    КонецЕсли;
КонецПроцедуры
```

5. **События команд:**

```1c
// Выполнение команды
&НаКлиенте
Процедура ЗаполнитьВыполнить()
    ЗаполнитьНаСервере();
КонецПроцедуры

&НаСервере

    // Серверная логика заполнения

```

**Паттерны именования обработчиков:**

- `Перед<Событие>` - до события
- `При<Событие>` - во время события  
- `После<Событие>` - после события
- `<Реквизит><Событие>` - событие реквизита
- `<Команда>Выполнить` - выполнение команды

## 3. Node Types Specification

Полная спецификация типов узлов AST (Abstract Syntax Tree) для Tree-sitter грамматики 1С.

### 3.1 Declarations (Декларации)

#### 3.1.1 procedure_declaration

**Описание:** Объявление процедуры

**Поля:**
- `annotations` (optional) - аннотации процедуры
- `keyword` - ключевое слово "Процедура"/"Procedure"
- `name` - имя процедуры (identifier)
- `parameters` (optional) - список параметров
- `export` (optional) - модификатор "Экспорт"
- `body` - тело процедуры (statement list)
- `end_keyword` - ключевое слово "КонецПроцедуры"/"EndProcedure"

**AST Example:**
```
(source_file
  (procedure_declaration
    annotations: (annotation_list
      (annotation
        name: (identifier)))
    keyword: "Процедура"
    name: (identifier)
    parameters: (parameter_list
      (parameter
        name: (identifier)))
    export: "Экспорт"
    body: (statement_list
      (call_expression
        function: (identifier)
        arguments: (argument_list
          (string_literal))))
    end_keyword: "КонецПроцедуры"))
```

#### 3.1.2 function_declaration

**Описание:** Объявление функции

**Поля:**
- `annotations` (optional) - аннотации функции
- `keyword` - ключевое слово "Функция"/"Function"
- `name` - имя функции (identifier)
- `parameters` (optional) - список параметров
- `export` (optional) - модификатор "Экспорт"
- `body` - тело функции (statement list)
- `end_keyword` - ключевое слово "КонецФункции"/"EndFunction"

**AST Example:**
```
(function_declaration
  keyword: "Функция"
  name: (identifier)
  parameters: (parameter_list
    (parameter
      name: (identifier)
      default_value: (number_literal)))
  body: (statement_list
    (return_statement
      value: (binary_expression
        left: (identifier)
        operator: "+"
        right: (identifier))))
  end_keyword: "КонецФункции")
```

#### 3.1.3 parameter_declaration

**Описание:** Объявление параметра

**Поля:**
- `val_keyword` (optional) - модификатор "Знач"/"Val"

## 4. Grammar Rules (Pseudocode)

Ниже представлена структура грамматики в псевдокоде JavaScript (формат Tree-sitter).

### 4.1 Базовая структура

```javascript
module.exports = grammar({
  name: 'onec',

  // Дополнительные символы (игнорируются парсером)
  extras: $ => [
    /\s/,          // Whitespace
    $.comment,     // Комментарии
  ],

  // Конфликты (для разрешения неоднозначностей)
  conflicts: $ => [
    [$.call_expression, $.member_expression],
    [$.metadata_access, $.member_expression],
    [$.parameter_declaration, $.identifier],
  ],

  // Inline правила (для оптимизации)
  inline: $ => [
    $._statement,
    $._expression,
    $._literal,
  ],

  // Приоритет операторов
  precedences: $ => [
    [
      'unary',        // Унарные операторы
      'multiply',     // *, /,  %
      'add',          // +, -
      'compare',      // =, <>, >, <, >=, <=
      'and',          // И / And
      'or',           // Или / Or
      'ternary',      // ?
      'assign',       // =
    ],
  ],

  // Основные правила грамматики
  rules: {
    // ... (см. ниже)
  }
});
```

### 4.2 Helper функция для регистронезависимости

```javascript
/**
 * Создает регулярное выражение для регистронезависимого сопоставления
 * @param {string} keyword - Ключевое слово
 * @returns {RegExp} Регулярное выражение
 */
function caseInsensitive(keyword) {
  return new RegExp(
    keyword
      .split('')
      .map(char => {
        // Для кириллицы
        if (/[а-яёА-ЯЁ]/.test(char)) {
          return `[${char.toLowerCase()}${char.toUpperCase()}]`;
        }
        // Для латиницы
        if (/[a-zA-Z]/.test(char)) {
          return `[${char.toLowerCase()}${char.toUpperCase()}]`;
        }
        // Другие символы без изменений
        return char;
      })
      .join('')
  );
}

// Примеры использования:
// caseInsensitive('Процедура') -> /[пП][рР][оО][цЦ][еЕ][дД][уУ][рР][аА]/
// caseInsensitive('Procedure') -> /[pP][rR][oO][cC][eE][dD][uU][rR][eE]/
```

### 4.3 Основные правила

```javascript
rules: {
  // ============================================
  // КОРЕНЬ ФАЙЛА
  // ============================================

  source_file: $ => repeat($._definition),

  _definition: $ => choice(
    $.variable_declaration,
    $.procedure_declaration,
    $.function_declaration,
    $.preprocessor_if,
    $.region,
    $.comment,
  ),

  // ============================================
  // КОММЕНТАРИИ
  // ============================================

  comment: $ => token(choice(
    seq('//', /.*/),           // Однострочный комментарий
  )),

  // ============================================
  // ДЕКЛАРАЦИИ
  // ============================================

  // Процедура
  procedure_declaration: $ => seq(
    optional($.annotation_list),
    field('keyword', caseInsensitive('Процедура')),
    field('name', $.identifier),
    field('parameters', optional($.parameter_list)),
    field('export', optional(caseInsensitive('Экспорт'))),
    optional($.statement_list),
    field('end_keyword', caseInsensitive('КонецПроцедуры')),
  ),

  // Функция
  function_declaration: $ => seq(
    optional($.annotation_list),
    field('keyword', caseInsensitive('Функция')),
    field('name', $.identifier),
    field('parameters', optional($.parameter_list)),
    field('export', optional(caseInsensitive('Экспорт'))),
    optional($.statement_list),
    field('end_keyword', caseInsensitive('КонецФункции')),
  ),

  // Список параметров
  parameter_list: $ => seq(
    '(',
    optional(seq(
      $.parameter_declaration,
      repeat(seq(',', $.parameter_declaration)),
      optional(','),  // Trailing comma
    )),
    ')',
  ),

  // Объявление параметра
  parameter_declaration: $ => seq(
    optional(field('val_keyword', caseInsensitive('Знач'))),
    field('name', $.identifier),
    optional(seq(
      '=',
      field('default_value', $._expression),
    )),
  ),

  // Объявление переменной
  variable_declaration: $ => seq(
    caseInsensitive('Перем'),
    field('name', $.identifier),
    optional(caseInsensitive('Экспорт')),
    ';',
  ),

  // ============================================
  // ОПЕРАТОРЫ (STATEMENTS)
  // ============================================

  statement_list: $ => repeat1($._statement),

  _statement: $ => choice(
    $.if_statement,
    $.for_each_statement,
    $.for_statement,
    $.while_statement,
    $.try_statement,
    $.return_statement,
    $.break_statement,
    $.continue_statement,
    $.raise_statement,
    $.assignment_statement,
    $.expression_statement,
    $.variable_declaration,
  ),

  // Условный оператор Если
  if_statement: $ => seq(
    caseInsensitive('Если'),
    field('condition', $._expression),
    caseInsensitive('Тогда'),
    optional($.statement_list),
    repeat($.elsif_clause),
    optional($.else_clause),
    caseInsensitive('КонецЕсли'),
    ';',
  ),

  elsif_clause: $ => seq(
    caseInsensitive('ИначеЕсли'),
    field('condition', $._expression),
    caseInsensitive('Тогда'),
    optional($.statement_list),
  ),

  else_clause: $ => seq(
    caseInsensitive('Иначе'),
    optional($.statement_list),
  ),

  // Цикл Для Каждого
  for_each_statement: $ => seq(
    caseInsensitive('Для'),
    caseInsensitive('Каждого'),
    field('variable', $.identifier),
    caseInsensitive('Из'),
    field('collection', $._expression),
    caseInsensitive('Цикл'),
    optional($.statement_list),
    caseInsensitive('КонецЦикла'),
    ';',
  ),

  // Цикл Для...По
  for_statement: $ => seq(
    caseInsensitive('Для'),
    field('variable', $.identifier),
    '=',
    field('start', $._expression),
    caseInsensitive('По'),
    field('end', $._expression),
    caseInsensitive('Цикл'),
    optional($.statement_list),
    caseInsensitive('КонецЦикла'),
    ';',
  ),

  // Цикл Пока
  while_statement: $ => seq(
    caseInsensitive('Пока'),
    field('condition', $._expression),
    caseInsensitive('Цикл'),
    optional($.statement_list),
    caseInsensitive('КонецЦикла'),
    ';',
  ),

  // Try-Except
  try_statement: $ => seq(
    caseInsensitive('Попытка'),
    optional($.statement_list),
    caseInsensitive('Исключение'),
    optional(field('exception_variable', $.identifier)),
    optional($.statement_list),
    caseInsensitive('КонецПопытки'),
    ';',
  ),

  // Возврат
  return_statement: $ => seq(
    caseInsensitive('Возврат'),
    optional($._expression),
    ';',
  ),

  // Прервать
  break_statement: $ => seq(
    caseInsensitive('Прервать'),
    ';',
  ),

  // Продолжить
  continue_statement: $ => seq(
    caseInsensitive('Продолжить'),
    ';',
  ),

  // Вызвать исключение
  raise_statement: $ => seq(
    caseInsensitive('ВызватьИсключение'),
    optional($._expression),
    ';',
  ),

  // Присваивание
  assignment_statement: $ => prec.right('assign', seq(
    field('left', choice(
      $.identifier,
      $.member_expression,
      $.subscript_expression,
    )),
    '=',
    field('right', $._expression),
    ';',
  )),

  // Выражение как оператор
  expression_statement: $ => seq(
    $._expression,
    ';',
  ),

  // ============================================
  // ВЫРАЖЕНИЯ (EXPRESSIONS)
  // ============================================

  _expression: $ => choice(
    $.identifier,
    $._literal,
    $.call_expression,
    $.member_expression,
    $.subscript_expression,
    $.binary_expression,
    $.unary_expression,
    $.ternary_expression,
    $.new_expression,
    $.parenthesized_expression,
    $.metadata_access,
  ),

  // Вызов функции
  call_expression: $ => prec('call', seq(
    field('function', choice(
      $.identifier,
      $.member_expression,
      $.metadata_access,
    )),
    field('arguments', $.argument_list),
  )),

  argument_list: $ => seq(
    '(',
    optional(seq(
      $._expression,
      repeat(seq(',', $._expression)),
      optional(','),  // Trailing comma
    )),
    ')',
  ),

  // Доступ к члену объекта
  member_expression: $ => prec.left('member', seq(
    field('object', $._expression),
    '.',
    field('property', $.identifier),
  )),

  // Доступ по индексу
  subscript_expression: $ => prec.left('subscript', seq(
    field('object', $._expression),
    '[',
    field('index', $._expression),
    ']',
  )),

  // Бинарные операции
  binary_expression: $ => choice(
    // Арифметические
    prec.left('multiply', seq($._expression, '*', $._expression)),
    prec.left('multiply', seq($._expression, '/', $._expression)),
    prec.left('multiply', seq($._expression, '%', $._expression)),
    prec.left('add', seq($._expression, '+', $._expression)),
    prec.left('add', seq($._expression, '-', $._expression)),
    
    // Сравнения
    prec.left('compare', seq($._expression, '=', $._expression)),
    prec.left('compare', seq($._expression, '<>', $._expression)),
    prec.left('compare', seq($._expression, '>', $._expression)),
    prec.left('compare', seq($._expression, '<', $._expression)),
    prec.left('compare', seq($._expression, '>=', $._expression)),
    prec.left('compare', seq($._expression, '<=', $._expression)),
    
    // Логические
    prec.left('and', seq($._expression, caseInsensitive('И'), $._expression)),
    prec.left('or', seq($._expression, caseInsensitive('Или'), $._expression)),
  ),

  // Унарные операции
  unary_expression: $ => prec.right('unary', choice(
    seq('-', $._expression),
    seq(caseInsensitive('Не'), $._expression),
  )),

  // Тернарный оператор
  ternary_expression: $ => prec.right('ternary', seq(
    '?',
    '(',
    field('condition', $._expression),
    ',',
    field('consequence', $._expression),
    ',',
    field('alternative', $._expression),
    ')',
  )),

  // Новый объект
  new_expression: $ => seq(
    caseInsensitive('Новый'),
    field('type', choice(
      $.identifier,
      $.type_reference,
    )),
    optional($.argument_list),
  ),

  // Выражение в скобках
  parenthesized_expression: $ => seq(
    '(',
    $._expression,
    ')',
  ),

  // ============================================
  // ЛИТЕРАЛЫ
  // ============================================

  _literal: $ => choice(
    $.string_literal,
    $.number_literal,
    $.boolean_literal,
    $.date_literal,
    $.undefined_literal,
    $.null_literal,
  ),

  // Строка
  string_literal: $ => choice(
    // Простая строка
    seq(
      '"',
      repeat(choice(
        /[^"]/,
        '""',  // Escaped quote
      )),
      '"',
    ),
    // Многострочная строка
    seq(
      '"',
      repeat(choice(
        /[^"|]/,
        '""',
        seq('|', /[^\n]*/),  // Продолжение строки
      )),
      '"',
    ),
  ),

  // Число
  number_literal: $ => token(seq(
    optional('-'),
    choice(
      seq(/\d+/, optional(seq('.', /\d+/))),  // Обычное число
      seq(/\d+/, /[eE]/, optional(/[+-]/), /\d+/),  // Экспоненциальное
    ),
  )),

  // Булево
  boolean_literal: $ => choice(
    caseInsensitive('Истина'),
    caseInsensitive('Ложь'),
    caseInsensitive('True'),
    caseInsensitive('False'),
  ),

  // Дата
  date_literal: $ => seq(
    caseInsensitive('Дата'),
    $.argument_list,
  ),

  // Неопределено
  undefined_literal: $ => choice(
    caseInsensitive('Неопределено'),
    caseInsensitive('Undefined'),
  ),

  // Null
  null_literal: $ => caseInsensitive('Null'),

  // Идентификатор
  identifier: $ => /[а-яА-ЯёЁa-zA-Z_][а-яА-ЯёЁa-zA-Z0-9_]*/,

  // ============================================
  // СПЕЦИАЛЬНЫЕ КОНСТРУКЦИИ
  // ============================================

  // Список аннотаций
  annotation_list: $ => repeat1($.annotation),

  // Аннотация
  annotation: $ => seq(
    '&',
    field('name', $.identifier),
    optional(seq(
      '(',
      optional(seq(
        $._expression,
        repeat(seq(',', $._expression)),
      )),
      ')',
    )),
  ),

  // Препроцессор #Если
  preprocessor_if: $ => seq(
    '#',
    caseInsensitive('Если'),
    field('condition', $.preprocessor_condition),
    caseInsensitive('Тогда'),
    repeat($._definition),
    repeat($.preprocessor_elsif),
    optional($.preprocessor_else),
    '#',
    caseInsensitive('КонецЕсли'),
  ),

  preprocessor_elsif: $ => seq(
    '#',
    caseInsensitive('ИначеЕсли'),
    field('condition', $.preprocessor_condition),
    caseInsensitive('Тогда'),
    repeat($._definition),
  ),

  preprocessor_else: $ => seq(
    '#',
    caseInsensitive('Иначе'),
    repeat($._definition),
  ),

  // Условие препроцессора
  preprocessor_condition: $ => choice(
    caseInsensitive('Сервер'),
    caseInsensitive('Клиент'),
    caseInsensitive('ТонкийКлиент'),
    caseInsensitive('ТолстыйКлиентОбычноеПриложение'),
    caseInsensitive('ТолстыйКлиентУправляемоеПриложение'),
    caseInsensitive('ВебКлиент'),
    caseInsensitive('ВнешнееСоединение'),
    caseInsensitive('МобильноеПриложениеКлиент'),
    caseInsensitive('МобильноеПриложениеСервер'),
    // Комбинации
    seq($.preprocessor_condition, caseInsensitive('И'), $.preprocessor_condition),
    seq($.preprocessor_condition, caseInsensitive('Или'), $.preprocessor_condition),
    seq(caseInsensitive('Не'), $.preprocessor_condition),
  ),

  // Область кода
  region: $ => seq(
    '#',
    caseInsensitive('Область'),
    field('name', $.identifier),
    repeat($._definition),
    '#',
    caseInsensitive('КонецОбласти'),
  ),

  // Доступ к метаданным
  metadata_access: $ => seq(
    field('metadata_type', $.metadata_type),
    '.',
    field('metadata_object', $.identifier),
    optional(seq(
      '.',
      choice(
        $.identifier,
        $.call_expression,
      ),
    )),
  ),

  // Тип метаданных
  metadata_type: $ => choice(
    caseInsensitive('Справочники'),
    caseInsensitive('Документы'),
    caseInsensitive('РегистрыСведений'),
    caseInsensitive('РегистрыНакопления'),
    caseInsensitive('РегистрыБухгалтерии'),
    caseInsensitive('РегистрыРасчета'),
    caseInsensitive('ПланыВидовХарактеристик'),
    caseInsensitive('ПланыСчетов'),
    caseInsensitive('ПланыВидовРасчета'),
    caseInsensitive('БизнесПроцессы'),
    caseInsensitive('Задачи'),
    caseInsensitive('ПланыОбмена'),
    caseInsensitive('Отчеты'),
    caseInsensitive('Обработки'),
    caseInsensitive('Перечисления'),
    caseInsensitive('Константы'),
    // Английские варианты
    caseInsensitive('Catalogs'),
    caseInsensitive('Documents'),
    caseInsensitive('InformationRegisters'),
    caseInsensitive('AccumulationRegisters'),
    caseInsensitive('AccountingRegisters'),
    caseInsensitive('CalculationRegisters'),
    caseInsensitive('ChartsOfCharacteristicTypes'),
    caseInsensitive('ChartsOfAccounts'),
    caseInsensitive('ChartsOfCalculationTypes'),
    caseInsensitive('BusinessProcesses'),
    caseInsensitive('Tasks'),
    caseInsensitive('ExchangePlans'),
    caseInsensitive('Reports'),
    caseInsensitive('DataProcessors'),
    caseInsensitive('Enums'),
    caseInsensitive('Constants'),
  ),

  // Ссылка на тип
  type_reference: $ => $.identifier,
}
```

## 7. Known Challenges

### 7.1 Регистронезависимость

**Проблема:**
Язык 1С полностью регистронезависимый. Tree-sitter по умолчанию чувствителен к регистру.

**Решение:**
1. Helper функция `caseInsensitive()` для генерации regex
2. Все ключевые слова обрабатываются через эту функцию
3. Идентификаторы также регистронезависимы

**Пример:**
```javascript
// Вместо:
'Процедура'

// Используем:
caseInsensitive('Процедура')  // -> /[пП][рР][оО][цЦ][еЕ][дД][уУ][рР][аА]/
```

**Ограничения:**
- Увеличение размера грамматики
- Небольшое снижение производительности
- Необходимость тестирования всех комбинаций регистра

### 7.2 Билингвальность (русский и английский)

**Проблема:**
Каждое ключевое слово существует в двух вариантах: русском и английском.

**Решение:**
1. Определение альтернативных вариантов для каждого ключевого слова
2. Использование `choice()` для выбора между русским и английским
3. Поддержка смешанного стиля в одном файле

**Пример:**
```javascript
procedure_keyword: $ => choice(
  caseInsensitive('Процедура'),
  caseInsensitive('Procedure'),
)
```

**Сложность:**
- Удвоение количества правил для ключевых слов
- Необходимость поддержки обоих вариантов в тестах

### 7.3 Кириллица в идентификаторах

**Проблема:**
Идентификаторы могут содержать кириллические символы.

**Решение:**
```javascript
identifier: $ => /[а-яА-ЯёЁa-zA-Z_][а-яА-ЯёЁa-zA-Z0-9_]*/
```

**Рекомендации:**
- UTF-8 encoding для всех файлов
- Тестирование на смешанных кириллица-латиница идентификаторах
- Поддержка буквы "ё"

### 7.4 Многострочные строки

**Проблема:**
Строки в 1С могут быть многострочными с использованием символа `|`:

```1c
Строка = 
"Первая строка
|Вторая строка
|Третья строка";
```

**Решение:**
```javascript
string_literal: $ => seq(
  '"',
  repeat(choice(
    /[^"|]/,
    '""',  // Экранирование кавычек
    seq('|', /[^\n]*/),  // Продолжение строки
  )),
  '"',
)
```

**Особенности:**
- Символ `|` в начале строки указывает на продолжение
- Перенос строки сохраняется в результате
- Используется в основном для текстов запросов

### 7.5 Запросы (Query Language)

**Проблема:**
Тексты запросов - это отдельный язык внутри 1С:

```1c
Запрос.Текст = 
"ВЫБРАТЬ
|    Товар.Наименование
|ИЗ
|    Справочник.Номенклатура КАК Товар";
```

**Возможные решения:**

**Вариант 1: Minimal (только распознавание)**
```javascript
query_string: $ => $.string_literal
```
- Простой
- Не парсит содержимое запроса
- Подходит для базовой поддержки

**Вариант 2: Full parser (отдельная грамматика)**
```javascript
// Создать отдельную грамматику tree-sitter-onec-query
// Использовать injection для вложения
query_string: $ => seq(
  '"',
  $.query_language_content,
  '"',
)
```
- Полный парсинг Query Language
- Сложная реализация
- Лучшая поддержка инструментов

**Рекомендация для Phase 1-2:**
Использовать Вариант 1 (minimal), затем при необходимости расширить до Варианта 2.

### 7.6 Динамические вызовы

**Проблема:**
1С поддерживает динамический вызов методов:

```1c
Выполнить("Процедура()");
ВычислитьВыражение("А + Б");
```

**Решение:**
- Парсить как обычные вызовы функций
- Строковые параметры - как string literals
- Не пытаться парсить содержимое строк
- Может быть расширено в будущем с помощью injection

### 7.7 Версии платформы

**Проблема:**
Разные версии 1С:Предприятие могут иметь различия в синтаксисе.

**Решение:**
1. Фокус на версии 8.3 (наиболее распространенная)
2. Документирование известных различий
3. Опциональная поддержка через флаги (в будущем)

**Основные различия:**
- 8.2 vs 8.3: минимальные (в основном совместимы)
- 8.3 vs 8.4: новые конструкции (стрелочные функции и т.д.)

### 7.8 Производительность

**Проблема:**
Большие файлы (10000+ строк) могут парситься медленно.

**Решение:**
1. Профилирование грамматики
2. Использование inline для часто используемых правил
3. Оптимизация regex паттернов
4. External scanner для сложных токенов
5. Инкрементальный парсинг (поддерживается Tree-sitter)

**Benchmarks (целевые):**
- Файл 1000 строк: < 50ms
