# docs/

Опциональная директория для проектной документации (отдельно от `~/.kilocode/`).

Рекомендуемый подход:

- правила/паттерны/workflow хранятся в `~/.kilocode/` (источник истины для агентов)
- `docs/` — для пользовательской или проект-специфичной документации (runbooks, onboarding, ADR-выжимки)

См. [~/.kilocode/workflows/documentation-workflow.md](../../../.kilocode/workflows/documentation-workflow.md).
