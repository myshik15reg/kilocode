# Унификация графовой кодовой базы

## Требования
- [ ] R1 Проанализировать текущую реализацию графовой кодовой базы (Neo4j), найти и исправить неточности.
- [ ] R2 Упростить и унифицировать модель/пайплайны так, чтобы она работала для всех языков, а не только 1С.
- [ ] R3 Переименовать файлы/пакеты/папки с 1С-ориентированными названиями в нейтральные.
- [ ] R4 Удалить/встроить лишние части, если логично интегрировать их в существующую семантику tree-sitter.
- [ ] R5 Обновить документацию и ссылки на новые имена/архитектуру.

## Принципы проектирования и стиля
- [ ] Не усложнять решение: без оверинжиниринга при сохранении требуемой функциональности.
- [ ] Решать проблемы самым простым способом.
- [ ] Использовать и переиспользовать существующие сущности; не создавать новые без необходимости.
- [ ] Доверять фреймворкам и не делать ненужных слоев оберток.
- [ ] Не вводить слои абстракции без необходимости.

## Критерии готовности (DoD)
- [ ] Покрытие = 100% (строки/ветвления/функции)
- [ ] Линтер: 0 ошибок / 0 предупреждений
- [ ] Чеклист безопасности пройден
- [ ] Документация обновлена
