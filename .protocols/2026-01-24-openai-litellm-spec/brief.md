# Спецификация интеграции OpenAI/ChatGPT Plus/Pro и маппинг для LiteLLM

## Требования
- [ ] Выявить и описать все точки интеграции OpenAI/ChatGPT Plus/Pro в текущем проекте (провайдеры, настройки, маршрутизация моделей, входные/выходные форматы).
- [ ] Детально описать поток данных агент ↔ UI ↔ провайдер (включая streaming, tool calls, обработку ошибок, usage/metrics).
- [ ] Разобрать параметр "усилия по рассуждению" (reasoning effort): где задается, как передается в запросах, какие значения поддерживаются и как отражается в ответах.
- [ ] Сформировать требования к backend для LiteLLM, который будет прозрачно работать с текущим агентом (контракты, поля, форматы, семантика).
- [ ] Подготовить артефакт-документ, пригодный как вход для Codex при реализации backend.

## Принципы проектирования и стиля
- [ ] Не усложнять решение: без оверинжиниринга при сохранении требуемой функциональности.
- [ ] Решать проблемы самым простым способом.
- [ ] Использовать и переиспользовать существующие сущности; не создавать новые без необходимости.
- [ ] Доверять фреймворкам и не делать ненужных слоев оберток.
- [ ] Не вводить слои абстракции без необходимости.

## Критерии готовности (DoD)
- [ ] Все точки интеграции описаны и снабжены ссылками на файлы.
- [ ] Поток данных и форматы сообщений описаны на уровне полей.
- [ ] Reasoning effort разобран с указанием путей в коде и примеров значений.
- [ ] Подготовлен артефакт-документ для Codex.
- [ ] `execution.md` обновлен ключевыми решениями/находками.
