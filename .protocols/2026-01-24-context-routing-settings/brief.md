# Контекстный роутинг в настройках контекста

## Требования
- [ ] Добавить настройку включения механизма контекстного роутинга.
- [ ] При включении показывать пороги fast/deep в настройках контекста.
- [ ] Сохранение/загрузка настроек через общий state и updateSettings.
- [ ] Отображать вычисленный режим (standard/fast/deep) в environment_details при включенном механизме.
- [ ] Обновить типы/схемы и тесты (100% coverage, TDD).

## Ограничения
- Node/TS only.
- Совместимость с Windows Server 2019.
- Минимальные затраты и быстрый отклик.

## Критерии готовности
- [ ] Настройки доступны в UI, корректно сохраняются и восстанавливаются.
- [ ] Режим роутинга вычисляется и попадает в environment_details при включении.
- [ ] Все тесты обновлены и проходят.
