# Анализ интеграции OpenAI (ChatGPT Plus/Pro)

## Требования
- [ ] Выявить, где и как в коде реализована интеграция с OpenAI/ChatGPT Plus/Pro (точки входа, слои, провайдеры).
- [ ] Описать конфигурацию: ключи, настройки модели, форматы запросов/ответов, маршрутизацию и маппинг моделей.
- [ ] Подробно разобрать параметр "усилия по рассуждению" модели (reasoning effort): где задаётся, какие значения, как влияет на вызовы.
- [ ] Подготовить инструкцию по повторению интеграции в другом проекте с ссылками на конкретные файлы.

## Принципы проектирования и стиля
- [ ] Не усложнять решение: без оверинжиниринга при сохранении требуемой функциональности.
- [ ] Решать проблемы самым простым способом.
- [ ] Использовать и переиспользовать существующие сущности; не создавать новые без необходимости.
- [ ] Доверять фреймворкам и не делать ненужных слоев оберток.
- [ ] Не вводить слои абстракции без необходимости.

## Критерии готовности (DoD)
- [ ] Все места интеграции найдены и описаны с ссылками на файлы.
- [ ] Параметр reasoning effort разобран с примерами значений и путём в коде.
- [ ] Подготовлена инструкция по повторению интеграции в другом проекте.
- [ ] Обновлён `execution.md` с ключевыми решениями/выводами.
